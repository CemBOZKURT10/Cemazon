# Cemazon
BPR201 İnternet Tabanlı Programlama - Final Projesi Cem Bozkurt 25115221003

Bu proje PHP ve MySQL kullanılarak geliştirilmiştir.

## 🚀 Kurulum
1. Proje dosyalarını `www` klasörüne atın.
2. `cemazon_db.sql` dosyasını phpMyAdmin üzerinden veritabanınıza "İçe Aktar" (Import) yapın.
3. Veritabanı adı: `cemazon` olmalıdır.
4. `cemazon_db.php` dosyasındaki kullanıcı adı/şifre ayarlarını kendi sunucunuza göre düzenleyin (Varsayılan: root, şifresiz).

## 👨‍💻 Özellikler
- Admin, Satıcı ve Müşteri panelleri
- Dinamik sepet ve stok yönetimi
- İndirim sistemi ve vitrin slider
